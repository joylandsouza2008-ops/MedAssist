# MedAssist (HTML)

Simple **HTML + CSS + JavaScript** prototype by **Team Orbit**  
(St Joseph Engineering College, Mangalore) for *Build for Billions — Agentic AI for Billions*.

## Open the app

1. Download / clone this folder.
2. Double-click **`index.html`**  
   or in VS Code right-click → **Open with Live Server**.

No install. No `npm`. Works offline in the browser.

## Features

1. **Explain prescription** — paste discharge / Rx → morning / afternoon / night plan  
2. **Cheaper options** — same-salt generic & Jan Aushadhi price bands (demo data)  
3. **Pharmacies** — sample Mangalore stock check  
4. **Scan** — type barcode or brand name  

Does **not** diagnose. Demo catalog only.
